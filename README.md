## An OS-agnostic Android flashing utility for Moto G54

## Requirements-
1. Brain
2. Eyes
3. PC
4. Phone
5. USB cable


## Setup
1. Install drivers if you are on windows. (Software fix will do it automatically for you).
2. Ensure [Android Platform Tools](https://developer.android.com/studio/releases/platform-tools) are in your System PATH.
3. Install python if it isn't installed already.
4. Clone the repo: `git clone -b python https://github.com/Vinay1a1/Motorola-custom-rom-tool.git`
5. Run: `python main.py`
