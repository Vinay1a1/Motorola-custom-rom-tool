## An OS-agnostic Android flashing utility for Moto G54

## Requirements-
1. Brain
2. Eyes
3. PC
4. Phone
5. USB cable


## Setup
1. Ensure [Android Platform Tools](https://developer.android.com/studio/releases/platform-tools) are in your System PATH.
2. Install python if it isn't installed already.
3. Clone the repo: `git clone -b python https://github.com/Vinay1a1/Motorola-custom-rom-tool.git`
4. Run: `python main.py`
